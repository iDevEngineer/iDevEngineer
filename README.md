# Hi 👋 I'm Scott Mackey

**AI consulting and automation, based in the United Kingdom.**

I help businesses find where AI saves real time, then build the automations, agents and tools that do the work.

### What I do

- 🧭 **AI consulting**: find the jobs worth automating and plan how to do it
- ⚙️ **Automation**: connect email, calendars, invoices and content so routine work runs itself
- 🤖 **AI agents and integrations**: custom agents, MCP servers and tools built on Claude
- 🖥️ **Apps and websites**: built with TypeScript, Next.js and Vue
